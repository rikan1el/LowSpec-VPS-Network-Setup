

# ⚙️ LowSpec VPS Network Setup

Скрипт безопасной оптимизации VPS с 1 vCPU / 1 GB RAM для стабильной работы:

* VLESS
* Xray
* 3x-ui
* других TCP/UDP-сервисов

Основная цель — повысить стабильность сети и снизить нагрузку на память на low-memory серверах.

---

## 🎯 Для чего нужен

На VPS с 1 GB RAM часто возникают:

* packet loss
* нестабильный TCP
* нехватка памяти
* перегруженный journald
* проблемы с conntrack

Скрипт аккуратно настраивает систему без агрессивного тюнинга.

---

## 🔧 Что делает скрипт

### 1️⃣ Swap

* Проверяет текущий swap
* Добавляет swap до ~1 GB (если нужно)
* Добавляет запись в `/etc/fstab`
* Создаёт файлы `/swapfile`, `/swapfile2`, и т.д.

---

### 2️⃣ Network sysctl (Low-Memory Safe)

Применяет щадящие настройки:

* `fq` queue discipline
* `bbr` congestion control
* Умеренные rmem / wmem
* Настройки UDP
* `nf_conntrack_max`
* `vm.swappiness = 10`

Файл конфигурации создаётся в:

```
/etc/sysctl.d/99-lowmem-network.conf
```

---

### 3️⃣ BBR

* Пытается загрузить модуль `tcp_bbr`
* Проверяет поддержку ядра
* Включает `net.ipv4.tcp_congestion_control = bbr`

Требуется ядро 4.9+.

---

### 4️⃣ Ограничение логов

Ограничивает systemd-journald:

```
SystemMaxUse=50M
```

Это снижает лишнюю нагрузку на диск.

---

### 5️⃣ Лимиты файлов

Увеличивает лимит `nofile` до 65536:

```
/etc/security/limits.d/99-rikori.conf
```

Полезно для Xray / прокси / серверов.

---

### 6️⃣ MTU (опционально)

Можно включить изменение MTU (по умолчанию 1450).

⚠️ Применяется временно (до перезагрузки).

---

### 7️⃣ Offloads (опционально)

Можно отключить:

* GRO
* GSO
* TSO

Через `ethtool`.

По умолчанию выключено (безопасный режим).

---

## 📦 Требования

* Linux VPS
* root или sudo
* systemd
* iproute2
* (опционально) ethtool

---

## ▶️ Использование

```bash
chmod +x lowspec_setup.sh
sudo ./lowspec_setup.sh
```

После выполнения рекомендуется:

```bash
sudo reboot
```

---

## ⚠️ Важно

* Скрипт рассчитан на low-memory VPS (1 GB RAM)
* Не предназначен для high-load production без понимания настроек
* MTU лучше тестировать отдельно
* Перед использованием желательно сделать snapshot VPS

---

## 🧠 Принцип работы

Скрипт:

* Проверяет текущие значения
* Не перезаписывает лишнего
* Применяет безопасные умеренные значения
* Не делает агрессивный тюнинг ядра

Главный фокус — стабильность, а не максимальная пропускная способность.
